# 验收、比较与返工

检查分层进行，记录证据而非统一写PASS。先读 [V2视觉事件契约](../../vibe-knowledge-script/references/visual-events.md)，核心事件未发生或变化不支持知识时即未通过，不能由美术、文字或音乐抵消。

## 扩展全片前

选择最可能失败的镜头：难画的主体、接触与形变、核心结果或声画转折。检查关键美术帧，再检查连续样段；长度足以暴露该风险即可，不固定前30秒或固定轮数。

与参考比较时匹配观察对象和尺度：主体轮廓、姿态、构图、材质、动作和字幕关系。不能仅凭都用了深色背景就说风格一致。参考片里看不到的原始软件、提示词、三维资产或母版参数，不作推断事实。

内部记录：`问题 → 具体帧/区间 → 修正方式 → 复查结果`。自己已经看见的明显问题不能带入全片。用户已授权制作时继续自主返工；只有确实无法满足已锁定内容，才说明具体缺口，不虚称已经完成。

## 五类检查

| 类别 | 检查什么 | 不足以替代它的证据 |
|---|---|---|
| 内容 | 题目、原稿重点、顺序与引用位置是否兑现 | 字幕字数足够 |
| 美术 | 主体好认且造型成立，画法符合参考，排版有层级 | 有高光、阴影或三维模型 |
| 动作 | 关键操作、接触、反应与落点连续可读 | 单个漂亮静帧 |
| 声音 | 材质对应、同步、掩蔽、动态与尾音 | 有音轨或波形峰值 |
| 媒体 | 尺寸、fps、帧数、时长、完整解码和编码后电平 | 文件存在、渲染器返回0 |

隐藏大多数解释性字幕，保留必要场景信息、对象标签、单位、定义和条件，判断发生什么、什么影响什么、怎样变化、结果如何承接。对照观看轨检查事件和必要文字，再以知识轨核对准确性与完整性；不要求字幕独立复述知识轨全文。基础过程完全不可读先改事件与镜头，不能加长文补救。

Canvas/WebGL 还需检查：主体是否足够大、反射和轮廓是否可辨，帧中有无 NaN 黑点、闪烁、摩尔纹、突变边缘或过度细密的背景；高光与颗粒不能掩盖主体。检查落水、断裂、落桌等事件前后若干帧，核对视觉首次接触与音效瞬态。比较起始、中段和后段的同帧复渲结果，不能只测组件最初的帧。

连续检查启动、过程、接触、结果和下一镜。手握持、织带端点、翻页轴、笔迹、阴影和物件位置要相互对应。取景应让关键细节在手机尺寸可见；不能用边角小字解释一个看不清的动作。

## V2事件验收

- 实际起态到结果有新状态、对照、揭示或理解，过程必要、结果可看清；不以切镜数量充数。
- 连续检查触发、动作、反馈和结果，身份/空间稳定、先触发后反应、接触/遮挡可信、转场保留信息。
- 事件区间占有效时长初始参考约70%，依题材和必要阅读调整；重叠区间取并集，必要阅读和标题不从分母删除，装饰动效不计分子。按实际时轴记录，有原因低于参考可说明，不硬凑数字。
- 节奏有适度预期、反应和结果反馈，不强制反转、全人物或全模型。
- 每事件标知识对应及真实性类别，不用虚构或隐喻证明未核实因果，不凭行为诊断心理。

区分静态状态图、实际连续样段、密集帧检查、实时播放与试听；报告真实检查范围，不把结构校验当审美或理解证明。

## 声音与媒体

按事件表核对关键声音确有画面依据，密集事件不重复堆叠同一种音效。重点检查开始、中段、密集处、转折与收尾；编码后再测响度、真峰值、削波与时长，验证没有静音轨、漂移或尾音截断。

静态图集不能证明已正常播放；信号测量不能证明已主观试听。能正常播放检查时应实际检查；能力不足时明确尚未验证的听感或播放部分，不把数值当作审美通过证明。

完整制作可从H.264/yuv420p、AAC/48kHz及1080p考虑，fps沿用确认要求。本系列默认1920×1080/30fps，除非用户明确变更契约；任何帧率都需实际动作验证，不能用重复帧冒充原生高帧率。无其他规范时，音频参考−16至−14 LUFS、真峰值≤−1dBTP，按编码成片复测。

## 最终交付范围

完整制作交付视频、实际封面、可复制简介和各自文件链接。只改技能或研究流程时，验收技能文件、引用、阶段边界与交接即可，不生成任何视频“验证一下”。


首五秒、基于渲染的导演检查及有限迭代见 [visual-qa.md](visual-qa.md) 与 [visual-director-workflow.md](visual-director-workflow.md)。这些补充不替代本文件的难动作、声音和媒体检查。
