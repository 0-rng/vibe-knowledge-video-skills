# 高级动效：把动词变成可观察过程

移植 LottieFiles 的情绪目标、视觉小故事、运动工艺与编排思路，渲染仍为 Remotion + Canvas/SVG/ThreeCanvas；不安装 Lottie 来获得审美。相关许可与差异见 [director-sources.md](director-sources.md)。

## 每次主动作的运动说明

先写目的与结束状态，再定：准备/蓄力、主动作、接触瞬间、反应、随动与稳定。小反馈无需强行蓄力；刚性机械、自由落体、匀速输送可按因果线性或物理轨迹，不执行上游“任何空间运动禁止线性”的绝对规则。

| 需要 | 实现选择 | 检验 |
|---|---|---|
| 蓄力 anticipation | 主位移前的小反向位移/预压，按镜头约0.08–0.2s起试 | 不像动作退错方向或拖慢回应 |
| 重要入场 | 快起慢收的贝塞尔；离场通常加速；场内移动按双方停点 | 速度曲线不是所有物件同一套 |
| overshoot | 仅弹性/轻件少量超调；刚体接触用约束停止 | 不穿透、不出现橡皮金属 |
| follow-through | 松散子部件延迟约0.05–0.15s或阻尼回摆 | 父件停止后子件仍短暂响应，最终归位 |
| staging | 降低无关层对比，主角轮廓/动势清晰，字幕与主动作错峰 | 第一眼能找到动作主体 |
| choreography | 一个时刻一项主变化，次级变化服务它，共享触发/几何 | 不是每个道具同拍同速运动 |
| 情绪节奏 | 好奇先遮后露；压力以受限空间/拉力累积；释放用余波收束 | 情绪来自状态与时长，不靠颜色标签代替 |

上表区间是试做起点，非平台规范或每镜固定配方。阅读、慢动作和情绪停顿可更长；快速动作也不可快到看不清因果。UI的500ms stagger上限、“只有1/3元素能动”、三层动画、20元素性能阈值不直接套进知识短片；群体运动、叙事长距离和干净静帧都可成立，必须有清晰视觉焦点。

## 帧驱动实现

复用 [../assets/motion-kit.ts](../assets/motion-kit.ts)：phase、eased、pose、arc、damped、revealRect；参数以秒/归一化进度表示，调用端由 frame/fps 换算，便于Canvas/SVG/Three共用。刚体、相机、柔性部件使用不同曲线，不自动对所有属性使用弹簧。路径只在含义需要时加弧线。

将动作事件id定义在一处：启动、接触、脱离、落地。画面位置/形变与声音编排都读取同一事件。每个声音检查有效瞬态（不只是音频文件头），目标距可见事件约50ms内；提前的whoosh也把主要重音放在视觉落点。

## 元素的进入、保留与退出

每个信息元素明确可见起止区间和保留原因：一次动作结束不等于对象必须消失；已经出现的对照、步骤或证据可能需要留到揭示后。临时标注在用途结束后退出，前镜遗留物只有在接续有意义时才保留。不要把“出现进度达到1”当作自动退场，也不要让短暂可见窗口擦掉尚未读完的内容。

通过明确的区间、状态和Remotion Sequence等实现生命周期；使用Sequence时核对useCurrentFrame的局部帧，与全片事件帧只换算一次。帧区间采用既有半开区间约定，退出边界不能重复绘制两镜的互斥状态。比较镜头在计划共同可见区间内保留双方，而非分别淡入淡出后只剩一方。

## 重复动作、计数与历史量

重复试验或批次用带稳定event_id的事件数据组织：开始、关键作用、结果和结束。对象变化、计数、标签与声音共同读取这些数据；计数由已发生结果推导，不能另开一套近似时钟。多个主体同帧发声仍是不同事件，不用“时间+声音名”粗暴去重。

累计曲线按frame/fps直接求值；可用解析函数、固定步长预计算或从确定检查点重放，按场景选合适方式。预计算时保留采样步长与单位，积分需要乘时间步长，显示插值不能改变已知事件结果。不得靠渲染回调次数累计，任意帧、乱序与分段导出都应得到相同状态。

事件可从分镜数据声明或从确定状态生成；若生成或采集失败，报告具体事件/镜头，修复后再导出，不能忽略异常后宣称声音事件完整。不引入上游截图引擎，也不把文档中的修复描述当作本地已验证实现。

## 镜头与形态

二维相机是舞台坐标的统一变换；字幕和品牌保持独立屏幕坐标。镜头拉远须揭示新空间，不是任意缩放。以共享几何决定遮挡、受力、前后层和接触阴影；变形保持可辨轮廓，软物件可近似保面积，但不可声称完整物理模拟。

时间高效的blur只作用于快速主体，可对同一解析轨迹子帧采样；避免全屏重复曝光掩盖错误。性能先测目标规格的5秒样段，渲染速度是离线吞吐，不冒充实时60fps。API以本地版本为准，先检查已有依赖再考虑新装。
