# 音乐、动作反馈与混音

## 选定音乐与结构

优先使用用户已选定且有适用授权依据的版本，沿用已有确认。记录曲名/常用名、具体来源、作者是否核实、授权依据与限制；上传者不自动等于作曲者。不要把热门曲名当作平台指定或开放许可。

没有音乐时，选择适合内容且可合法使用的本地/网络素材，或确实可用的原创音乐生成方式；明确来源。简单合成适合短音效，不能将随机正弦循环宣称为完成的高质量配乐。

分析音乐时区分：

1. 起音：某个声音开始或能量突增，不必然是节拍。
2. 节拍与强弱拍：规律脉冲及其组织，节拍估计可能出现半拍/倍拍歧义。
3. 乐句与能量变化：铺垫、发展、转折、收束，是叙事编排的依据。

先让重要故事变化对应合适乐句，再微调动作与拍点。不要把每个动作吸附到最近波形峰；不要为踩拍破坏先发起后回应、先靠近后连接等因果。保留用户指定音乐速度，必要调整要有明确目的。

## 先设计声音行为，再选择音色

先判断声音要表达运动过程、物件接触、阻碍反馈、状态改变还是结果，再选择声源和音色。声音必须有对应可见行为，允许留白，不得用强音效伪造画面没有发生的动作。抽象动点可用合成音，具象任务可用有合适材质感的录音或合成音；不要求所有片子使用拟音，也不把同一正弦音换音高当作全部声音设计。

移动或旋转的持续声可随速度、距离和方向变化；短瞬态标记接触或完成；尾音表达余韵。按需要组合，不给每个动作强行加满三层。失败、未完成和真正成功应有可辨别差异，避免每次状态亮起都使用同样的奖励声。

同类声音适度保持一致；发起与回应可以同族而有所区别。为重要结果保留更清楚的落点，为犹豫、发现和转折保留安静空间。声音事件表数量不作为丰富度或质量指标。

## 事件与声音的对应

| 可见事件 | 可选声音 | 触发依据 |
|---|---|---|
| 卡片开始移动/落定 | soft whoosh + light pop | 起步与停止分别定位，整体保持轻 |
| 重要文本或关键词 | tick / light pop | 整组信息落定，不逐字机械触发 |
| 点出现、状态亮起 | glass ping / synth blip | 可见状态改变 |
| 擦肩或快速经过 | 短空气掠过 | 交错或最近位置 |
| 靠近、蓄势 | gentle rise / soft pulse | 随动作发展，到关键点收住 |
| 线条生长/完成 | synth sweep +双音chime | 生长起点与抵达终点 |
| 主动与回应 | 同族但略有音色区别的pluck/bell | 先后两个独立事件 |
| 重要结论 | warm pulse / tonal hit | 结论落定，仅用于真正重点 |
| 转场 | 按方向、速度定长度的air/whoosh | 能量峰对应视觉重点，不是每切镜必响 |
| 收尾 | resolution / airy tail | 留出衰减，不突然截断 |

具体音色是设计建议，未听参考原片时不得说成原片真实音效。相近事件合并或衰减，三张卡同时出现就按真实动作配声，不人为编成依次出现。

有物件任务时，补充受阻、摩擦、调整和接合等与实际动作相关的声音；几何或数据动画则选择适合其抽象语义的提示，不给无材质的图形硬套具象碰撞。

## 精确同步

为事件记录对象ID、视觉依据、目标帧、目标毫秒、音频开始采样、瞬态偏移、增益、音高、声像和淡入淡出。Whoosh的开始可以早于视觉重点，但主要能量应与动作匹配。

音频放置公式：`start_sample = round(target_time × sample_rate) − transient_offset_samples`。负值时调整素材前导或时间安排，不让数组负索引错误地写入尾部。瞬态偏移由实际素材测量或试听校对，不能用文件起点冒充。

关键瞬态尽量与视觉落点相差不超过约50ms。RMS能量峰、绝对采样峰和听感落点不同，报告使用哪一种。新设计给计划时间；已有工程优先用源代码时间；仅有视频时注明帧定位误差。

## 混音与检查

音乐支撑整体情绪；动作提示应清楚但不压过主体。必要时短暂降低音乐或让出频段，避免把全部音效抬高。音调类提示与音乐和声协调，声像适度跟随主体。

与参考片比较前先匹配整体播放响度，避免将更响误判为更有质感。有源分轨时可比较关键事件附近的能量、频段和尾音累积，用于寻找掩蔽候选；RMS差值不等于人耳响度差，也不能单独证明掩蔽。只有混音时，不把波形峰当作已分离的音效或声源身份。

关键落点不清楚时，先检查声源是否对应动作、瞬态是否准确、音乐频段是否拥挤，再调局部让位与增益。不要照抄参考片的整体响度和过高峰值来补救叙事或取景问题。

有旁白时在内部工程保留可独立调整的旁白层，并只在讲话段适度ducking；无旁白时不要创建虚构旁白轨。分轨与声音事件表用于编排和检查，不默认导出为交付附件，除非用户明确索要。控制低频尾音和混响累积，检查单声道折叠、手机频段可辨识度与突变。

没有其他要求时可参考−16至−14 LUFS integrated、True Peak≤−1dBTP；这是制作目标，不是本技能核实的平台硬性标准。以编码后成片复测为准。

音频检查覆盖开头、中间、密集事件、转折和结尾；检查缺轨、静音、削波、延迟和尾音截断。只做了信号测量就如实记录，未主观试听不能声称听感已验证。


## 材质拟音的补充检查

选声音时按实际接触材质与动作选：细沙流动、纸张翻折、笔尖刮擦、织物受力与松开、物件落桌，不能由同一个短电子音包办。复杂连续声优先使用合适的录音；合成可以补短瞬态和抽象反馈，但不能只用未经试听的噪声循环冒充精细拟音。持续声的音量包络跟随速度或受力，接触瞬态对齐动作落点，释放时停止不应继续的摩擦。

有声样段与全片在正常播放下检查材质辨识和音乐掩蔽。仅存在音效文件、数量足够或绝对峰值对齐，不表示声音已经贴合画面。旁白不存在时不创建旁白轨；分轨保留在内部编排，不默认作为用户附件。
