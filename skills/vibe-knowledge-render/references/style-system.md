# 系列风格与开放表达

读取现行[STYLE_BIBLE](../assets/cinematic-style/STYLE_BIBLE.md)。用户2026-10-21已取消旧三张图及固定三帧确认门槛；旧附件、approved-keyframes和STYLE_APPROVAL仅保留历史，不自动加载为新话题基准。最新要求优先，不从旧图反推内容与构图。

## 保留辨识，让表达开放

默认横屏1920×1080/30fps，暗色整体、真实中文字体与账号品牌沿用；调色和字体令牌作为系列基础。暗底允许高对比浅色主体，不要求暗脸、复杂室内、写实人物或满屏纹理。

人物、图形、材质、取景、场景复杂度、背景层数与运动按内容选择。简化人物、直接图解、模型与适题的其他画法均可；不强制A–F母版、五层齐全、每镜隐喻或轮流换背景。稳定背景下持续发生有意义的动作完全可用。组件帮助复用，不成为创作边界。

## 先说明发生什么

分镜按实际需要交代空间/舞台、主体关系、造型/材质、明暗/灯光、构图/安全区、动作与结果。平面图形写简化造型与对比设计即可，不虚填体积光、焦距或复杂材质。状态说明比图的张数重要。

选案需要看画面时按实际分歧出图，数量和形式服务判断；只要文字或只改技能时不出图。不凑氛围、数据、概念三类图，不要求每个动作画固定三格；没有数据不为画面编造数据。

## 复用与实际验证

可复用[组件包](../assets/cinematic-style/package.json)、[组件](../assets/cinematic-style/src/visual-system/components.tsx)和[tokens](../assets/cinematic-style/src/visual-system/tokens.ts)，也可在同一工程扩展适题主体。Remotion统一帧号，等待真实字体与素材就绪；重要中文由真实字体绘制，生成图不烘焙关键文字。不升级既有依赖或自动下载浏览器。

[结构校验](../assets/cinematic-style/scripts/validate-style-contract.py)只查技术与字段，不判断观赏性，也不以旧keyframeReview决定整片能否制作。没有JSON计划时不为校验器另造交接文件。

制作范围由用户授权决定；已授权且输入足够时，自主实现、真实样段检查、修订与交付。只要图或样段就止于该范围。仍检查前5秒、风险事件连续片段、声音与媒体；静帧不能证明流畅。每阶段按[独立反驳](../../vibe-knowledge-script/references/adversarial-review.md)检查，不新增固定图片审批。
