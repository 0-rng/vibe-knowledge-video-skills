# Canvas 逐帧动画：画出过程与材质

用户已认可“水滴入海”样段的方法：Canvas + JavaScript 驱动每帧，复杂水面由 WebGL 着色器绘制，Remotion + 本机 Chrome 导出。此文件只指导选择Canvas/WebGL时的实现；V2允许按事件选SVG、分层素材或角色动画等方法，见 [引擎](engines.md)。不能为保持Canvas把关键行为替换成长字幕或几何装饰；换API本身也不保证好看。

## 按镜头选择绘制方式

| 镜头需要 | 合适方式 | 关键实现 |
|---|---|---|
| 人物剪影、手绘路径、文字书写、绳带拉伸、纸张轮廓 | Canvas 2D | 路径控制点、局部变换、裁剪与前后层；形变必须实际变化 |
| 水面、反射、折射、连续高度场、密集粒子 | Canvas WebGL / GLSL | 几何或高度场、法线、光照和遮挡；解析求值或确定性重放 |
| 字幕、引用、手机屏幕、信息标签、图表标注 | HTML/CSS/SVG 或 Canvas | 保持清晰排版，与主体绑定相同事件时间 |
| 需要真实骨骼或空间结构的物件操作 | 合格资产 + 适当渲染方式 | 先解决资产、姿态和接触，不用着色器掩盖错误造型 |

不要把所有场景都做成水波、发光球或粒子。动画应让观众看懂“发生了什么、怎样发生、造成什么结果”。

## 帧绘制契约

- 用 `t = frame / fps` 和场景局部时间绘制。Canvas 2D 每帧完整清理、恢复变换并重画；WebGL 对当前帧绑定正确的 program、viewport 和 uniforms。不能让上一帧内容意外残留。
- 粒子位置由出生时间、速度、加速度和年龄计算，固定随机种子；状态模拟从固定初始条件或确定检查点重放。乱序 seek、重复帧、分段渲染均应得到相同状态。
- Canvas 内部分辨率按输出像素尺寸设置，而非只扩大 CSS 宽高。WebGL 的 viewport、分辨率 uniform 与实际画布一致；动态分辨率只能在验证画质后明确采用。
- 在 React 的绘制 effect 中完成目标帧，再解除关联的 Remotion `delayRender`。对异步素材和 GPU 绘制显式等待就绪，错误用 `cancelRender` 终止，不能把空画布作为成功帧。
- Canvas WebGL 逐帧捕获可用 `preserveDrawingBuffer: true` 保留结果，并在绘制完成后等待提交；已验证样段使用 `gl.finish()` 后解除等待。此策略有性能成本，优化时必须复查实际导出，不能只看实时预览。
- 不自由运行 CSS 动画、`requestAnimationFrame` 或墙钟。Remotion 是唯一时间源，字幕、音效、粒子和场景切换共享它。

## 先把动作拆成因果阶段

以实际对象与同一接触面计算动作，安排启动、加速、接触、形变、反应与衰减。各阶段的速度和时间尺度不同，不把整段统一套一个 easing，也不为每个物件添加弹跳。

液体示例：下落形状与速度变化 → 首次接触 → 局部凹陷与飞溅 → 回弹水柱或分离水珠 → 波纹传播、衰减和融合。水滴底部和动态水面首次相交的时刻才是触水事件，音效绑定该事件；“预设时间到了”不能覆盖可见间隙。粒子在回落触水后消失或转化，不凭空擦除。

涟漪由同一接触中心和传播时间控制，在水面空间扩散，再经过统一投影与遮挡。需要起伏时用位移或高度场带动法线与高光；只缩放描边圆环不能替代水面反应。其他题材按相同原则处理裂纹、弯曲、沙粒流动与烟雾，而非照搬液体阶段。

## 材质、光照与构图

- 轮廓和尺度先可辨，再叠加厚度、渐变、光照与纹理。接触阴影、反射、亮边随对象的位置与形变更新；主光方向保持一致。
- 透明物体用透射色、边缘反射和局部高光建立形态。反射与折射按能力近似，不将高度场与解析水珠称为完整流体求解。
- 水面或颗粒背景控制空间频率和对比度，远处逐渐减少高频细节，避免摩尔纹和闪烁。关键动作应在手机尺寸下看清；必要时进入近景，而非用字幕解释一个过小的主体。
- 沿用本片美术与字幕层级。青蓝、写实反射和电影式水面不是 Canvas 的必选外观。

## WebGL 故障与速度

着色器先检查编译、链接及目标浏览器的 context。GLSL 避免 `flat` 等保留字；对平方使用 `x*x`，不向 `pow()` 传负底数。归一化、分母、折射和交点计算需处理退化值，检查 NaN 黑点、错误高光和消失的表面。

高度场交点要稳定收敛：按坡度和误差选带边界的求根或其他经过验证的方法，不能依靠少量迭代后留下黑斑或穿透。反射是近似时保持视觉连续，不宣传不存在的物理精度。

先用已安装 Chrome 导出小样，确认 WebGL 可用、画质和实际速度，再决定并发与分辨率。渲染参数沿本机安装版本核实；不为换技术无谓下载浏览器或重复安装已有依赖。GPU 绘制和硬件视频编码是两项能力，分别核实，不把其中一项可用等同于全流程已加速。
