# 暗色电影感编辑式动态视频 · 风格锁定规范 v1.0

## 用途
将任意主题转化为与指定参考视频**视觉语言相近、内容与隐喻原创**的分镜和最终动画。目标：电影级暗色氛围 + 精致宋体排版 + 信息可视化 + 可解释的符号隐喻 + 克制且连续的动效。避免逐镜照搬参考视频的具体内容、图表、画面和文字。

## 参考视频可观察到的视觉规律
- 参考文件：`抖音20261018-244849.mp4`，约115秒，1280×720，30fps，16:9。
- 字体：暖白色中文衬线正文/标题；英文微型章节注释、数字和UI辅助信息偏简洁无衬线，章节序号使用大型极细描边。
- 配色：近黑午夜蓝、葡萄紫、暗酒红；暖白；局部珊瑚粉/香槟橘强调；图表局部冰蓝发光。
- 画面：丰富暗部、局部发光、微弱浮尘和颗粒、强留白。用图表、发光节点、象征物代替直白人物表演。
- 不同场景在“寓意对象”上变化，但保持光线品质、排版、纹理、配色、镜头运动、微动画一致。

## 视觉风格固定项：严禁在分镜中擅自改动
### 画幅与技术
- 主画幅16:9，1920×1080，30fps；若需9:16，重新排版，不能把横版机械裁切。
- 场景内所有重要中文文字、图表刻度、微UI均由矢量文字/SVG/HTML绘制，不能烘焙进入生成背景图。
- 只生成“无文字背景图 / 独立概念元素”，再用程序合成文字与图表。
### 颜色设计令牌（建议值）
- `--night: #090D16` 深海蓝黑；`--aubergine: #1C1122` 暗葡萄紫；`--wine: #25171B` 酒红黑；
- `--ivory: #F0E7DC` 主文字；`--muted: #8B8792` 弱文字；`--coral: #E7A292` 重点；`--ice: #81C5E9` 数据强调；`--gold: #CFAD7D` 微暖光。
- 每镜头仅1个主强调色，必要时1个次强调色；不使用高饱和霓虹混色。
### 背景统一五层
1. Base 基底：几乎黑色的深蓝/暗紫/暗红渐变，保留色深，不是死黑。
2. Atmosphere 氛围：极轻胶片颗粒，低不透明度烟雾、微尘与少量远景离焦光点。
3. Motif 概念主体：每镜仅1个优先的视觉隐喻，抽象图形/孤立物件/线性图表，视觉克制。
4. Light 光场：一处有方向的主光源 + 极微弱边缘补光，暖光只落在重点物体或关键词周围，禁止泛滥的光晕。
5. Layout 留白：主体元素与文字不冲突，文字区域保持低视觉噪声并有充足安全边距。
### 字体与排版
- 主标题/关键句：思源宋体（Source Han Serif SC）或 macOS 宋体（Songti SC）近似，字重 Regular/Medium，暖白。
- 英文小注、时间刻度与标签：Inter、Helvetica Neue、思源黑体等无衬线。章节编号：超轻量描边01/02，禁止厚实实心大号字。
- 1920×1080下建议：标题50–76px；副句32–44px；微标签16–22px；章节描边数字190–280px；按镜头与字数调整，不能统一死值。
- 主文优先每屏1–3行，最多1–2个重点词变色，不出现大段说明文字。保持段落优雅的分行、呼吸感和足够行距。
- 常用构图：左文右图、右文左图、居中大句、单物体中央与边缘微注释，交替使用。
- 背景图画面禁止包含文字、logo、水印、UI伪文字。文字后期以程序渲染。
### 视觉元素库
- 电影性：窗格投影、斜射暖光、暗室局部聚光、浮尘、纸质便签。
- 概念性：孤立球体、花瓣、细线星点人体、大脑脉冲、拓扑节点、环形时间弧。
- 信息性：细线概率曲线、折线、统计轴、百分比、微卡片、水平进度线、实验序号。
- 每镜最多选择一种主元素语法，不得杂糅成科技UI仪表盘。
### 动效约束
- 基础：淡入/淡出、逐词出现、细线描边增长、图形渐变点亮、微弱景深变化、缓慢推进和小范围视差。
- 元素动作遵循解释顺序：先画面问题/现象，后图形建立，最后高亮结论。
- 字的登场动画轻盈，关键字在句末略晚出现；图形尽可能有内在逻辑（曲线由左向右生长，数值变化时同步绘制）。
- 微动常态持续，不得整屏长时间完全静止。
- 参考建议：入场0.35–0.8秒，镜头主要停留2.5–6秒；避免每次都使用统一节奏，最终以配音语义为准。
### 禁止项
- 纯黑空底加白字连续出现、深色粒子背景全片重复、赛博朋克、蓝紫大霓虹、未来城市、夸张镜头甩动、过多三维炫技、默认PPT样式和粗厚卡通图标。
- 同屏过多图形、光污染、背景写实人物表演抢戏、任意换字体、每镜随机换主色。
- 把生成式图片中的乱码当字幕直接使用。

## 给AI描述每一个背景的六维模板
每个分镜必须写成以下六项具体说明，不能只写“高级黑色背景”：
1. 空间：如午夜蓝无边界黑场、暗酒红虚化摄影棚、古典暗室窗光。
2. 概念主体：只选一个与主题观点对应的**可视化隐喻**；说明它在画面中的精确位置、比例、造型。
3. 材质：哑光、半透明磨砂面板、纸张肌理、细线光迹或点状颗粒。
4. 光源：方向、色温、衰减位置、明暗范围；最多一主光一辅光。
5. 构图：文字安全区（如画面左侧45%保持安静）、主体占比，景深/空间层级。
6. 时间：0-1秒什么出现，1-2秒什么生长，2-4秒哪个元素点亮，退场如何完成。

## 稳定的AI工作流程
1. 首先从新话题提取“观念／冲突／因果／证据／结论”，不改风格。
2. 将每个观点转化为视觉隐喻（不是每句话都硬塞一个人物；优先可动画化的简洁符号）。
3. 选择母版A–F，使连续两个场景不得只是同一黑底加两行不同字。
4. 给出每镜背景的六维描述、文字分层、构图、运动轨迹、声音节奏与持续时间。
5. 用静态无字生成图或CSS/SVG制作背景，由Remotion/After Effects/其它合成框架统一绘制中文和动态图表。
6. 先输出3个关键帧供设计校验（开头/数据解释/结论）；对照风格契约检查，再批量渲染。
7. 导出主版 1920×1080 /30fps，必要时改排9:16。

## 可直接发给 GPT / Claude / Codex 的总提示词
你是电影级动态设计导演、编辑视觉设计师、Remotion动画工程师。请将用户输入的任意话题制作成高质感知识短视频。

**设计约束高于话题内容**：必须遵守本文件的全部“风格固定项”。可以改变的只有故事结构、概念隐喻、图表数据和必要的道具，不能改变配色体系、光线品质、字体家族、背景层次、设计节奏和排版规则。

禁止把整片处理成纯黑底白字、重复星空粒子、PPT逐页换页、赛博科技HUD。禁止仅凭“高级”“精致”“电影感”这样的抽象词描述画面。每镜必须输出确切可绘制的背景细节、灯光、材质、元素坐标、文字安全区、时间和动作。

请先输出：《视频风格契约校验》；《逐镜分镜表（时间、旁白、屏幕短句、视觉隐喻、母版、背景六维、动效、音效）》；《首三镜静态关键帧布局方案》。只有风格和镜头设计完成后再编码实现。

实现时优先用Remotion + React + CSS/SVG组织全片；字、图表、章节编号程序绘制；图像生成只负责不含文字的背景/道具；保证中文字清晰且一致；图形行为随语义变化，背景微动但不过度。依照用户提供的旁白长度与预期总时长决定场景数量，不要自动套固定模板数量。

自检每一个镜头：底色是否属于调色盘？有无真实空间层级？主体是否是准确视觉隐喻？是否只有1个主重点？文字是否可读？背景有没有和文字抢焦点？动效是否有因果变化？相邻镜头是否有设计变化但仍属于同一个系列？有一项不合格请修改，而不是降低标准。

用户话题：{在这里写入新的主题}
目标时长：{如45-60秒}
输出比例：{16:9 或 9:16}
旁白/文案：{若已提供则严格使用；未提供时先生成文案}

## 用于AI生成无字背景图的英文统一前后缀
Prefix: `Dark cinematic editorial motion graphics aesthetic, near-black midnight navy and aubergine gradients, sophisticated low-key lighting, extremely restrained atmospheric haze, delicate film grain, sparse floating dust motes, subtle depth of field, elegant negative space, premium art direction, matte materials, cinematic composition, soft localized bloom.`

Middle: `{具体场景物体与构图。例如：a single paper receipt hanging in a warm narrow spotlight on the right third of frame, the left half kept nearly empty and dark for later typography, gentle diagonal shadow planes, minimalist theatrical composition}`

Suffix: `No visible letters, no words, no subtitles, no logo, no watermark, no clutter, no cyberpunk neon, no colorful gradients, no futuristic city, no full-screen stars, no overexposed highlights, no cartoon illustration. Background plate only. 16:9.`

> 注意：为实现真正的一致性，单靠提示词无法百分百锁死生成图片；设计令牌、可复用图形组件、同一合成环境及关键帧校验，比长提示词更可靠。
