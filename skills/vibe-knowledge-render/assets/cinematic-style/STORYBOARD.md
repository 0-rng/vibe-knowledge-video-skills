# 三张风格校准关键帧的独立分镜

> 历史风格示范，非现行创作基准；2026-10-21取消旧三图及固定三帧审批。不自动读取本示例，不将道具、布局或镜头复制到新话题。

本轮仅验证系列视觉；三镜为各自5秒的独立composition设计，不是已制作的15秒视频。实际输出为各composition第90帧（3秒）的PNG。

## style-atmosphere · 母版A
- 空间：午夜蓝与酒红黑暗室；右墙与地面以倾斜透视交接，文字侧保持低对比
- 概念主体与隐喻：右侧单张折叠纸，主包围盒x1178–1575、y295–740，薄边与折面形成层次。用窄光选择一个孤立对象表达注意焦点；仅为风格示范，不作心理学证据
- 材质：哑光折纸，半透明薄边；低对比墙面与细胶片颗粒
- 灯光：key / 右上斜射至右中纸面 / gold / 光束集中于x1100–1750，左文区保持暗部；fill / 纸张右上薄边 / ivory / 仅边缘极弱反射
- 构图与安全区：左文右主体；墙面、纸面、投影三层；文字矩形[144, 275, 850, 475]；主体矩形[1178, 295, 400, 450]。均为1920×1080坐标。
- 时间动态：0–0.35秒：暗室空间与窄光建立，少量光束内尘埃持续漂移；0.25–1.1秒：两行宋体依次轻移淡入；1.1–2.0秒：副句出现，纸张做幅度3px的解析式微动；2–5秒：保持阅读，光场与投影微变，尾态承接后镜

## style-data · 母版C
- 空间：午夜蓝低噪声数据实验空间，图表下方有薄弱空间折面与局部冰蓝明度
- 概念主体与隐喻：右侧一幅同坐标折线对照，主线冰蓝、对照线弱灰虚线；轴与数据由同一坐标计算。直接可视化同尺度下的差异，避免另加无关隐喻
- 材质：细矢量轴线、微弱线迹光晕与低透明度面积，不用卡片仪表盘
- 灯光：key / 图表中下部局部反射 / ice / 图表附近衰减至暗部，文字区低噪声
- 构图与安全区：左侧标题与差值，右侧图表；坐标、图例保留真实字体；文字矩形[144, 270, 605, 590]；主体矩形[780, 290, 940, 485]。均为1920×1080坐标。
- 时间动态：0.2–0.8秒：轴线与网格建立；0.25–1.1秒：宋体标题依次出现；0.6–2.2秒：A/B线由左至右显现，差值数字读取同一进度；2.2–5秒：终点与18单位差值稳定，保留图例和明确示意标注；本镜无漂浮粒子

## style-concept · 母版D
- 空间：暗葡萄紫概念空间，下半部展开单一拓扑分支，远景暗红折面提供纵深
- 概念主体与隐喻：同一起点分出七条可能路径，一条珊瑚色路径被逐步描出；构成一个关系模型。用分支关系示意选择与后续路径的联系，不虚构概率或实验结论
- 材质：超细低透明度曲线、少量节点与局部珊瑚反射；轻雾而非满屏粒子
- 灯光：key / 下半部路径中段偏右 / coral / 光场局限于路径附近，标题后保持安静
- 构图与安全区：居中单行主句，上文下图；语义标签置于路径端点附近；文字矩形[200, 220, 1520, 190]；主体矩形[450, 420, 1190, 490]。均为1920×1080坐标。
- 时间动态：0.25–1.1秒：居中宋体主句出现；0.7–2.2秒：珊瑚色路径从共享起点生长；1.1–1.8秒：副句出现；2.2–2.6秒：目标端点点亮；2.6–5秒：拓扑关系保留，空间与稀疏远景尘点持续微动
