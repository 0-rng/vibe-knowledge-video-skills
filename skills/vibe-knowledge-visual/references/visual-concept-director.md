# 视觉概念比较与选择

输入：第一阶段的观看轨与事件链，知识轨、内容基调、关键主张/beat、事实边界、锁定项、目标规格及已有参考。完整知识正文不是字幕输入。输出：关键节点的不同视觉机制、实际概念图、推荐理由和待验证风险；按用户要求展示选项并等待选择，不输出完整导演分镜。

## 实际参考与概念图

先检索有关场景、操作、艺术或动画参考，写明具体启发与本片的原创转换。按 [画面选案](visual-options.md) 为可比较的整体方向生成实际图像并展示；不得用三个文字提示词冒充三张图，也不将推荐当用户选择。

## 不同机制的候选

对开头、核心机制与重要转折按实际分歧比较差异明显的表达，不规定最少三案；同一节点同时承担多个角色时不重复凑组。用户只改一个镜头或已经锁定方案时按该范围处理；普通过渡、定义与总结沿用已成立场景，不机械地每句生三套。

候选用短段记录：

`concept_id / claim_id / beat_id / event_id → 对应关系 → 具体对象与可识别状态 → 对象关系 → 改变关系的动作/作用 → 先后过程 → 可观察结果与新理解 → 必要文字及理由 → 当前资产/技术能力 → 情绪与误读风险`

每案用这八项问题检验：看到什么对象、有哪些状态、对象有什么关系、什么改变关系、变化如何依次发生、看到哪个结果能理解、哪些文字仍不可省、技术能否可信实现。每案说清起态、过程、结果，按判断需要给实际图示，不只写“大致变化”，也不强制三张图。

具体情境、同条件对照、机制展开、遮挡揭示、尺度变化、空间关系翻转或形变均可考虑。不同道具若仍是同一种“受力后丢失”，可能只是同一个创意的变体；发光、粒子与震动本身不算新的表达机制。

## 相对比较

先使用 [内容关联检查](content-visual-mapping.md) 判断语义。若大段字幕才能连上关系、静态构图没有有意义变化、道具联系靠文字强解释、事件不能支持知识或关键动作已知不可实现，淘汰重做；待验证的资产风险应具体，不伪装为已具备。通过后再比较首眼辨识、预期与新信息、情绪、理解成本、整片一致性、资产能力与制作风险。给具体取舍，不编评分、流失秒数与留存率。

优先一个清楚而有发现的大胆方案，不把几案拼成效果合集。难度高时写可验证风险与保留含义的替代路径，不直接许诺精细手部、复杂流体或未知模型能力；也不能因现成组件方便而默认退回平庸卡片。

## 选案的最小交接

给出推荐concept_id及原因、放弃其他有竞争力方案的原因、一句可检验视觉主张、最可能的误读与失败征兆。说明哪些对象关系和信息变化不可改，哪些构图或素材可以替换。

把整片主题与各beat连成一条认识变化，不以一串互不相关的物件清单交接。等待用户选择后确定美术brief，并交接选中concept_id、对应观看事件、参考出处、关键状态说明及按需图示、必要文字与真实性边界。逐镜首帧、取景路径、动作时长、阅读节奏与接续由第三阶段展开。

规格未定的新视频默认横屏16:9、1920×1080；旧项目或用户明确指定的规格优先。概念图按横屏组织近景细节、整体揭示与文字区域；用户指定竖屏时另行构图，不直接缩小或裁切横屏整幅。手机尺寸辨识仍需第四阶段用实际画面检验。
