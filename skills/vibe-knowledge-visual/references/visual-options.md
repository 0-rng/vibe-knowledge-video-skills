# 实际画面候选：让用户看着选

第二阶段在用户已选内容方向后执行。默认检索视觉参考、提炼表达机制，并生成实际概念图供用户比较；只交提示词或文字描述不算完成可视化选案。用户本次明确只要文字时可不出图。只修改技能的任务不现场生成无关示例图。

## 搜什么、提炼什么

从已选内容的关键关系出发，搜相关的物理现象、具体操作、图解、艺术表达、摄影、动画或视频画面。提炼内容如何通过画面或文字表达，不把某条影片预设为全片画风；沿用现行STYLE_BIBLE的暗色基调和真实字体，造型、背景与运动按内容开放比较，不用旧三图限制。可用网页和图片搜索；打开原页检查语境、对象关系与画面出处。挑能帮助解决本题的参考，不按热度堆图，不默认只找同题材短片。

记录 `参考链接 → 有用的构图/关系/变化 → 怎样转换成本片表达 → 与原作的差别与风险`。用户给的参考先看；网络图可启发选择，不自动有权下载、编辑、再分发或作为正式资产使用。

关键节点的机制候选按 [视觉概念比较](visual-concept-director.md) 形成，再组织为按分歧组织的连贯视觉方向。每套有同一核心内容，但表达关系或观看机制有真实差异；不要靠配色变化伪装成不同方案。

## 让状态与变化可判断

每个整体方向必须明确起始状态、关键变化与结果；以状态说明和必要姿势/图示交代核心过程，不硬性生成三张或三格。按实际分歧提供足够可比较的方向，不逐beat重复凑图。用户指定数量或只要文字时按要求，明确哪些状态尚无图，不把缺图写成已验证。图外编号与状态说明真实字体合成。

新视频未指定时以横屏16:9、1920×1080为目标构图，已有项目或明确指定规格优先。用一致的目标画幅、内容承诺和必要文字约束比较方案；系列基础色感和真实字体延续，人物、场景复杂度与表现方法可以比较，不以旧图锁定。图要呈现同一对象的身份、关系、构图与前中后状态；同时写明状态间实际发生的动作、作用与反馈，不能靠切成另一张构图跳过机制。状态图不是已渲染的连续动画；不再另设导演定稿后的固定三帧美术检查。所有重要中文、标签、轴刻度与微UI必须由真实字体程序合成，禁止烘焙在生成图内。

## 工具与输出

需要概念素材时读取已安装的 `$imagegen`，用内置 `image_gen` 只生成无字背景或独立元素；可直接代码绘制的图形则复用组件。正式关键帧用统一Remotion合成，不以AI文字概念图代替。每个方向分别调用，明确内容发现、所保留关系、对象与状态、画幅、构图、风格、参考角色和禁改项。用户提供的本地图片先实际查看；编辑既有图也按imagegen的编辑流程执行。

简洁的关系图或布局草图若天然适合SVG/Canvas，可直接绘制并展示，但要标明草图性质；不能用占位图替代用户要的美术概念图。允许调用共享Remotion组件渲染静帧；不因此启动TTS或整片视频。

实际检查每张结果的语义、主体辨识、关系方向、文字与风格，明显不对应候选的图先修正。AI图可能暗含不可实现的复杂资产或物理效果；标明这是概念提案，运动与接触能力留到第四阶段验证。

逐案内联展示真实图片，标明A/B/C与对应concept_id，配简短内容关联、参考启发、预期动作、优势、误读风险与实现风险，最后给推荐理由。项目需要保存的候选图存到项目目录并提供实际文件链接；内置工具只返回内联媒体时使用其真实结果，不能虚构本地路径。

## 等用户选择

用户可以选一案、组合部分元素、要求换方向或继续迭代。未选择前不定视觉基调，不继续完整导演分镜；“推荐B”和图已生成都不代表用户选B。选择后记录已选concept_id、实际图片路径或真实媒体引用、美术与语义锁定项、起始/动作中/结果序列、必要文字、实现路径与仍未验证的动作风险。

用户明确授权代理代选时才跳过此等待；已有选案不重复确认。模型或工具不可用时说明当前只完成了文字/参考图选案，不能说已生成图片；按imagegen规则处理备用路线，不擅自换付费API或索取密钥。
