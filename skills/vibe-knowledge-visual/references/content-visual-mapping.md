# 内容和视觉之间必须有可说明的关系

这是第二阶段的核心检查。先读 [视觉事件共同契约](../../vibe-knowledge-script/references/visual-events.md)。优先基于观看轨的事件链创作，以知识轨核对依据；视觉吸引力、语义有效性和实现能力分别判断，不能互相替代。

## 抽取需要保留的关系

先从观看轨的claim/beat/event找到对象、起始状态、触发、作用、条件、方向与可观察结果。明确观众应多理解哪一项：分清概念、看见过程、比较差别、感受代价、理解范围，还是在新语境下重读一句话。

不是所有内容都是因果链。分类、定义、观点、引文和情绪体验可以分别用边界、对照、文本或情境表达；不要为“演起来”编造内容中不存在的受力或因果。

每个关键节点记录：`知识主张/观看事件 → 必须保留的关系与条件 → 表达类型 → 起始状态 → 关键动作/反馈 → 结果状态 → 观众新理解 → 必要文字及理由 → 证据性质/类比边界 → 选案理由`。普通过渡句可沿用已有场景，不要求逐句填一行。

## 选择表达类型

| 内容需要 | 可考虑的表达与选用理由 | 必须保留的东西 |
|---|---|---|
| 具体对象、真实过程或操作 | 直接呈现对象，运行一个最小完整过程，让动作承担解释 | 顺序、条件、接触与结果；不能只摆出起点与终点 |
| 条件差异 | 同条件对照，使观众看见改变一个变量带来的差别 | 初始状态与单位可比；关键差异同时在场或可可靠追踪 |
| 数量或分布 | 图表、计数、空间尺度，让长度、面积或数量有明确含义 | 来源、单位、分母与尺度；标出真实数据或示意，不虚构读数 |
| 需要亲自察觉的感知现象 | 简短的观看任务或感知体验，让变化先被察觉 | 实际呈现条件与观看限制；不是心理诊断，也不冒充严谨实验或普遍结果 |
| 概念区分或关系整理 | 分类、边界、并置、重组，或将已介绍对象收拢成关系图 | 分类依据、例外、连线含义；箭头不能暗示资料不支持的因果 |
| 抽象关系或内心体验 | 具体情境或解释性隐喻，让难以直接看到的关系可追踪 | 对应关系与类比边界；不是给抽象词贴日常物件标签 |
| 历史事件 | 时间、人物、空间与关键事件推进 | 史实来源、重建和未确定部分分开 |
| 哲学命题 | 具体困境、选择及结果关联观点 | 情境帮助思考，不把虚构结果当证明 |
| 引用、命名、总结 | 文本主导或保留已建立的尾态，让已有关系获得清楚表述 | 语境、阅读时间与论证作用；不强塞新道具，仍沿用系列空间和光照 |

选型后只需一句理由，例如“本段难点是区分输入和处理速度，所以让两者分别可见并同时计数”。复杂节点可组合表达；不为了覆盖清单逐项使用。共同判断是：屏上是什么、发生什么、观众凭什么多理解一步。不把所有机制演成人物故事，文字也不必全部可视化；核心动作要说明起态、过程与结果，按判断需要补图，不强制三张/三格；单帧不证明事件成立。

## 最小演示与可比尺度

演示只保留必要对象，但关键过程要完整。沿同一对象展示输入、作用、输出和限制条件；多步过程分阶段增加信息，不靠“变成了另一张图”跳过需要解释的步骤。

数量比较先定单位和编码方式，再设计外观。同一比较中的轴尺度、面积/半径和计数口径保持可比；必要换尺度时明确标出。图表、数值、标签和动画的变化来自同一数据。若某个真实量能贯穿多个例子，可以重复呈现帮助连接；没有可定义的量时用对象身份或问题接续，不发明“执念值、幸福值”等心理分数，也不强求常驻仪表。

两个原创检查例子，仅说明方法，不作为默认题材或道具：

- **过程示意**：解释“积压取决于进入与处理的差”。只让队列越变越长，观众不知道为何。可以在明确标为假设的情境中，每轮进入3件、处理2件，从空队列开始让剩余量变成1、2、3件；两端动作与计数同步。它解释给定条件下的关系，不证明现实中的某个群体或系统必然如此。
- **对照示意**：比较同一信息的两种排列。先看A再彻底擦掉看B，会迫使观众靠记忆比较。保留相同文字、数量和尺寸，让两种排列并置或让同一批元素可追踪地重排，标清真正变化的条件；只能呈现差异，未经测试不能宣称哪一种提高了阅读效率。

## 三种常见的错误关联

**物件只与词面相似。** 正文谈“关系压力”，画面只是一个写着压力的重物；若没有展示压力来自哪里、如何改变关系，只是贴标签。应找出该段真正讨论的关系再设计。

**物理规律替人际结论作证。** 握沙漏出可以表达抓紧与失去的张力，但不能证明“越爱越被拒绝”。若正文讨论反馈与控制，画面至少需要保留相应条件，并明确只是示意；不能靠字幕短注挽救整段错误因果。

**把关注对象画成被压迫者。** 内容若讨论“过度关注反馈使自己的生活收缩”，只画手机挤压另一个人容易变成“你在伤害对方”。可以比较“待回复状态持续占据日程”等更接近本段关系的方案；这仍是解释性情境，不是普遍结论或实验记录。

例子用于展示检查方法，不是所有情感题目的默认道具或创意库。

## 让视觉有发现

第一眼建立可追踪的关系，变化改变观众对它的理解。新信息可以来自被遮住的条件、整体尺度、此前行为的结果或对照差异；不一定靠反转。普通解释镜头只要过程清楚也能成立。

避免全片每段重新建立一个完全无关的隐喻。选一个可发展的主体或关系作锚点，让后续内容真正改变它；换场景时继承一个问题、对象身份或状态。也不要为统一意象让每段都重复同一个结论。

## 选案与风险

先检验关系与误读，再比较首眼辨识、情绪、新鲜度、统一性与资产成本。每案写一条最可能失败的原因；有风险但值得做的方案可进入第四阶段验证，不以“实现最省事”覆盖创意判断。

方案若只靠大段字幕、美丽静构图、强行解释道具，或变化不支持主张、关键动作无可信实现路径，退回重做。按 [八问与选案](visual-concept-director.md) 检查对象、状态、作用、顺序、结果、文字与能力。

输出语义成功条件，例如“观众能看到同一反馈状态怎样占据越来越多日程”，而非“高级、治愈、有电影感”。第三阶段据此安排观看过程；第四阶段据此检查实际画面。

如果核心内容本身矛盾、过度绝对或没有支撑，返回第一阶段修正文。不要把事实问题藏进隐喻，不要为了保留漂亮画面另写一个用户没要的结论。
