# Vibe 视觉分镜导演 · 视觉事件驱动 V2.1

镜头是事件发生的空间。先导演对象的变化、作用与结果，再安排必要文字、版式、灯光与装饰。读取 [视觉事件共同契约](../vibe-knowledge-script/references/visual-events.md)、[风格体系](../vibe-knowledge-render/references/style-system.md) 和 [STYLE_BIBLE](../vibe-knowledge-render/assets/cinematic-style/STYLE_BIBLE.md)，沿用系列基础，按事件自由组织画面，不把旧图或静态美术当作事件成立。

## 独立反驳与优化

形成本阶段可评审初稿后，默认开启一个独立子智能体，按[评审流程](../vibe-knowledge-script/references/adversarial-review.md)质疑演绎效果与视觉观赏性；主创核对反驳、修订后复查关键节点，再展示结果。不得用自评冒充独立意见，或用静帧证明动作流畅。通常最多两轮，核心问题未解决如实交代。只改技能或零碎勘误不机械运行四阶段。

旧三张参考图不再作为创作或验收基准；取消固定三帧确认门槛。需要图时按当前问题选择数量与形式，不凑三类图、不靠旧图锁定人物、场景或表现手法；已有用户选择与制作授权边界继续保持。

## 输入与职责

优先读取已选**观看轨**、事件链、视觉八问、状态说明及可用图示；以**知识轨**核对依据、关键条件、顺序、引文与用户锁定项。缺知识发现返回`$vibe-knowledge-script`，缺有效机制返回`$vibe-knowledge-visual`；已有输入能用直接用。完整研究正文不是默认字幕表。

跨阶段与局部修改读 [协作](../vibe-knowledge-script/references/workflow.md)。本阶段交导演候选、静态状态序列、完整分镜与验证计划，不制作动画、TTS或音频。可用`$imagegen`生成无字素材或程序绘制，再用真实字体合成静态图；只修改技能不出图。已有路径或明确授权直接细化时不重复选案。

## 研究与观看路径选择

按 [导演选案](references/director-options.md) 定向检索开头、核心事件和难点的镜头、操作与剪辑参考，说明实际查看范围和具体启发，不由一张图虚构整段动作或声音。

保持已选内容与机制，通常给2–3条关键观看路径，比较先看到什么、暂时忽略什么、触发如何出现、动作与反馈顺序、何时发现结果、情绪及阅读负担。可复用状态图，必要时补静态粗分镜。不重开全文和美术，不只给快中慢三种速度。

给理由后等待用户选择，未选前不展开某案完整分镜。明确选择或已有授权后再细化，不能靠等待超时自选。

## 先事件，再镜头

按 [完整字段](references/director-storyboard.md) 将一项知识发现组织成可观看事件。一个事件可跨镜，一镜也可承载连续相关事件，不一镜一句话、不按固定秒数均切。每镜必须明确：

1. **起始状态**：空间、对象位置/姿态、已有关系与当前状态。
2. **触发**：什么使对象行动、条件改变或系统变化。
3. **主动作**：谁先动、方向、移动与稳定部位、速度变化。禁用“展示焦虑、体现联系、产生情绪”代替行为。
4. **接触/阻碍/反馈**：位置、受力、遮挡、响应及改变；无实体接触时写其他可观察作用。不存在阻碍可明确无，不为凑结构造冲突。
5. **结果与余波**：可见的新状态、观众获得的信息、保留多久及后续影响。
6. **观看顺序**：观众先认出什么、何时看到条件和结果；镜头运动用于揭示，不用于使静态画面看似在动。
7. **文字补充**：事件安排后再决定，写实际显示内容、用途、阅读窗口及不可省理由。

按实际表达说明styleVersion、空间/舞台、主体关系、造型/材质、明暗/灯光、构图/文字安全区、分阶段动态。平面动画不虚填复杂灯光和材质，不必套固定母版或更换背景。写出首帧、可见线索与预期、揭示、尾态与接续，给camera、motion、sound、资产及实现风险。二维写实际舞台变化，不虚填焦距。

## 文字、阅读与声音

叙事镜头默认优先无解释字幕；必要时用短词短句，普通镜头可参考单屏约8–12个汉字以内，按阅读难度调整。标题、图表、定义、引用及不可缺条件不机械限字；不能靠缩小字号或延长整片容纳文章。无旁白也不把知识轨全文搬上屏。

按 [运动与阅读](references/motion-and-reading.md) 错开复杂动作与阅读高峰。停留服务于看清过程、结果、必要知识或情绪；缩短优先删重复与空等，不统一加速。

声音只写可见事件、材质、力度、启动/移动/接触/反馈/结果及留白，使用event_id。音乐沿用已确认版本，精确音画时点由第四阶段同一事件表产生，不虚构已卡点。

## 无字幕导演测试与连续性设计

按 [分镜审查](references/storyboard-review.md)，暂时隐藏解释性字幕，保留场景必要信息、轴名、单位与不可缺条件。逐关键段落检查：发生什么、什么影响什么、怎样变化、结果如何承接。无需无字讲清全部术语；基础过程完全不可读时先改事件和顺序，不加长字幕补救。

检查起态到末态是否有新变化，中间是否跳步，身份与空间是否稳定，反应是否晚于触发，接触/遮挡是否可信，结果是否有观看时间，转场是否保留必要信息。此时是静态序列与设计推演，不声称已验证运动、实时播放或声音；明确交第四阶段用连续样段核对的区间与成功条件。

## 按需预览与交付

默认横屏16:9、1920×1080、30fps，已有要求优先。选定后交双轨版本引用、导演意图、完整事件分镜、必要文字、声音意图、风险样段和锁定项，以稳定`shot_id / beat_id / concept_id / event_id`关联。Markdown足够时不额外生成JSON；机器接口需要时再按字段参考输出。

需要帮助判断时，按难点给必要姿势/状态图或粗分镜；数量不限死，不强制氛围/信息/概念三图及其批准。独立子智能体检验事件是否有可观看过程与吸引力，修改后交接风险区间和成功条件；实际动作是否流畅仍由制作阶段用连续证据检查。无真实数据不编数值。

只做策划止于策划；完整制作授权下，后续技术样段由`$vibe-knowledge-render`自主验证，不新增审批。知识失真回第一阶段，机制不成立回第二阶段，时机与接续在本阶段修。来源见 [说明](../vibe-knowledge-script/references/director-sources.md)。
