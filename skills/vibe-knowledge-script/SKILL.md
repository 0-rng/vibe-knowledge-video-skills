# Vibe 内容创作发散 · 视觉事件驱动 V2.1

先找到值得讲且有依据的知识发现，再找到观众能跟随的变化。基本单位是“一项发现对应一段可观看事件”，不默认先写文章再拆字幕。先读 [视觉事件共同契约](references/visual-events.md)，按`研究与发现 → 现实情境或机制选择 → 可观看事件链 → 知识核对 → 必要文字`工作。

## 独立反驳与优化

形成本阶段可评审初稿后，默认开启一个独立子智能体，按[评审流程](references/adversarial-review.md)质疑演绎效果与视觉观赏性；主创核对反驳、修订后复查关键节点，再展示结果。不得用自评冒充独立意见，或用静帧证明动作流畅。通常最多两轮，核心问题未解决如实交代。只改技能或零碎勘误不机械运行四阶段。

旧三张参考图不再作为创作或验收基准；取消固定三帧确认门槛。需要图时按当前问题选择数量与形式，不凑三类图、不靠旧图锁定人物、场景或表现手法；已有用户选择与制作授权边界继续保持。

## 范围、输入与锁定

本技能负责第一阶段，之后依次为`$vibe-knowledge-visual`、`$vibe-knowledge-storyboard`和`$vibe-knowledge-render`。首次交接或版本修改读 [四阶段协作](references/workflow.md)。本阶段设计事件语义，不锁定资产、核心视觉隐喻、镜头坐标或帧号；只讨论、写稿、点评或改技能时不生成图片、视频和音频。

提取题目、立意、主张、关键原句、顺序、引文位置、时长、旁白与本次范围。已有决定保护，未定项才发散。新片默认横屏16:9、1920×1080、30fps，后续沿用；系列续作读 [项目偏好](references/account-profile.md)。按当前项目选择STYLE_BIBLE、真实字体、品牌和音乐；人物与场景按内容设计，不读取旧三张图限制发散。

- 只有题目：实际联网研究后给通常3–5个方向，等待用户选择，不内部代选进入下游。
- 明确要求直接成稿或授权代选：仍研究与发散，说明取舍后交双轨剧本；一般“执行前三步”不等于代选。
- 有大纲或正文：以编辑为默认，保留重心、口气、结构和明确锁定句。完整正文首先作为知识轨；将适合的机制整理成观看轨，不将整篇文章直接转字幕。
- 只要诊断或局部修改：指出问题、影响与改法，只覆盖开放范围；不自动重写全篇或启动完整制作。

会改变核心发现、论证顺序或已锁定屏幕原句时，说明影响并按已有授权处理，不能用转换观看轨悄悄改意。缺项先从会话推断，仅询问影响本轮决策的部分。

## 研究、发现与候选

按 [检索到选案](references/research-to-options.md) 真实联网，覆盖事实与原始语境、相关选题及现实处境、反例与边界。打开有用原文、从初搜扩展关键词，记录可追溯链接；不只搜单一平台、不堆摘要、不声称穷尽全网。无法访问就说明核查范围。

按 [内容发散](references/content-development.md) 比较不同问题、尺度、机制、条件和选择，差异应改变认识增量，而非换标题。每案明确`资料发现 → 灵感 → 本案增加什么理解`，并给：

1. **知识主张**：解释什么、观众原先如何理解、看完增加什么认识。
2. **演绎潜力**：知识是否有可见行为、关系、机制、对照或结果；不足时寻找真实例子、实验或适合模型，不改成空泛隐喻。
3. **事件链**：通常3–6个关键节点，按内容增减；逐节点说明起态、动作/作用、反馈与新结果、下一步的原因和理解增量。不是角色轮流说金句。
4. **必要文字**：概念名称、关键条件、数据、定义或结论及保留理由，不预设整篇解说上屏。
5. **真实性**：分别标明真实事件、研究结论、典型情境、虚构演绎、假设模型和视觉隐喻；说明来源及不能推出什么。
6. 开头事件或问题、推进与收束、情绪、价值、风险、推荐理由及来源。

事件链是内容解释提案，不提前替用户选视觉机制。候选紧凑可比，不写3–5份完整双轨长稿。给推荐后等待选择；无答复或超时不是同意，可继续查证独立资料。

## 选定后交双轨剧本

按 [结构与表达](references/story-design.md) 和需要时的 [开头与推进](references/hooks-and-retention.md)，使每个beat增加因果、条件、证据、区别或选择，开头承诺得到兑现。不得用单个聊天故事接管复杂论证，也不强迫所有内容变成小剧场。

- **知识轨**：完整依据、逻辑、必要解释、引用与事实边界，供创作核对；原正文保留在这里。
- **观看轨**：观众实际看到的事件、状态、行动、反馈、结果、有限屏幕文字和理解推进。关联`claim_id / beat_id / event_id`，指出与知识轨的对应，供下游优先使用。

无旁白不等于用字幕补齐知识轨全文。先使过程与后果可见，再留下不可省的定义、条件和结论；必要限定必须在成片中有效呈现。镜头、精确动作与时长留第三阶段，计划时间不冒充实测。

涉及真实知识、实验、古籍与规则读 [资料核对](references/research.md)，学习公开方法再读 [来源](references/sources.md)。不把相关写成必然因果，不用虚构情境证明机制，不凭行为诊断心理，不把金句当科学定律。用户只要文章时按其范围交稿，不擅自启动事件影片制作。

## 交付与复查

未选时交研究发现、3–5案、事件潜力、来源和推荐，止于选择。选定后按 [内容交接](references/handoff.md) 交双轨剧本、内容基调、出处、边界、版本、锁定和待选项。已有选择不重复问。

结合独立评审复查：发现有依据；观看轨确有信息性变化；事件支持主张且未越界；必要文字不是研究正文复制；用户立意与关键句保留。内容不成立先修内容，不交动画包装。第二阶段优先读观看轨设计视觉机制，以知识轨核对真实性。
