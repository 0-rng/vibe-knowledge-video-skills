# 内容发散：先找发现，再写成一条片子

适用于开放选题与方向未定；已有稿件只对用户开放的部分使用。发散不是增加候选数量，而是比较不同的内容主张。

## 必须从实际检索获得输入

按 [从全网检索到用户选案](research-to-options.md) 先搜核心问题、相关选题、具体处境与反面解释，读有用原文并从结果扩展搜索。每案展示来源发现、引出的灵感和新增内容；至少几个站点的同一篇转载不算独立视角。

## 从题材缩到可回答的问题

先区分：题材是什么、观众遇到什么、通常怎样理解、本片提供什么新的区分或解释。题材宽时从具体处境切入，但保留用户要讨论的层级，不把复杂主题缩成一个方便动画的例子。

例如“执念”是题材，可以探索“追求为何逐渐占据生活”“什么时候坚持变成失去反馈”“如何区分重视结果与把价值押在结果上”等问题。它们的正文、依据与结尾都不同；并非已验证的心理学定律，也不默认用于所有执念题目。

结合题目从不同维度展开：经验与反例、个体与环境、短期与长期、原因与后果、概念误区与具体选择、传统引文与现代语境。挑有实际差别的路径，不需要把维度清单全部填满。探索性请求通常展示三到五个有区别的方向，附来源与灵感并等待用户判断；用户指定数量或已有选择时按其要求。明确要求直接成稿或代理代选时可说明取舍后继续，不能把一般的“帮我做”理解为代选。

## 每个方向是一份最小内容提案

用紧凑段落交代：

- **问题与处境**：观众为什么会关心，不用“所有人都这样”的空泛共情。
- **核心发现**：看完能复述的一句话；明确是事实、解释、观点还是实践建议。
- **直觉与增量**：比常见说法多解释了什么，是否有值得澄清的条件或反例。
- **理解障碍与最小例子**：观众具体卡在哪里；用哪个小例子把遗漏的关系或条件讲清，哪些数据来自资料、哪些只是演算假设。
- **论证骨架**：靠什么事实、逻辑或经验性观察支撑，关键跳步在哪里。
- **叙述与情绪**：陪伴、冷静拆解、惊讶、沉思等怎样由内容产生，不靠标签指挥观众感受。
- **承诺与边界**：本条片子能回答什么、不能推出什么，收尾会落在哪里。

每案必须补足 [V2事件提案](visual-events.md)：知识主张、演绎潜力、通常3–6个按需增减的事件节点、必要文字及理由、真实性分类。写起态、动作/作用、反馈、结果与下一步为何发生；不是只记一个画面灵感。内容阶段提出事件语义，不锁定具体资产、构图、镜头或技术，潜力不能冒充已验证实现。

最小例子只保留解释所需的对象和条件，至少把关键一步及结果讲完。真实个案标来源；假设演算写明输入；虚构情境不得包装成实验或亲历。用例子检查“这段解释成立吗”，不是用它代替全部论证；定义、引文和哲学判断也可直接解释，不强制改成故事或先案例后结论。

## 选方向时保留反对理由

优先比较：用户原意、认识增量、证据或推理强度、观众相关性、题目范围与情绪诚实性。每个有竞争力的方向写一个反对理由或可能失效条件，不编分数和留存预测。

以下问题应先修：核心结论只是口号；反常识依赖偷换概念；用个案代表普遍规律；结论超出证据；开头的问题与正文无关；“适合动画”成为唯一选案理由。不要为制造冲突抹掉现实中的复杂条件。

推荐一案并说清为什么，停在选项等待用户选择；其他方向可保留为后续题目。不要把互不相容的主张拼成“更丰富”的一条片子。缺关键事实时先查证，或明确降为待核对观点，不能带着伪确定性进入定稿。

## 把方向发展成双轨剧本

先把研究发现转成具体情境、机制或对照的候选事件链，再核对它能否支持知识主张，最后提取必要文字。知识轨保留完整论证，观看轨按事件组织“前一状态→动作/反馈→新状态→新理解”；无需凑固定层数，不一镜一句话。保留用户指定层级与引用位置。

开头承诺与结尾发现对读；中段若删去一段仍完全不影响理解，检查是否重复。共情、停留和诗性表达有作用时保留，但不充当不存在的因果。重要限定应出现在相关句子，而非只在稿后撤回正文的绝对断言。

用“观众能复述什么”检查价值，而非用金句密度检查价值。无旁白按事件与必要文字协作组织，不默认把全文上屏；有旁白按其明确范围处理。两者都不能靠虚构经历或权威身份增强可信度。

## 本阶段基调记录

双轨剧本之外留下一段简洁记录：`问题 / 一句发现 / 观众处境 / 立场与情绪 / 开头承诺 / beat及增量 / 收束 / 依据与边界 / 锁定项与待选项`。

判断可以进入第二阶段的条件：读者能说清本片讲什么、为什么相信、看完多懂了什么，且这些答案没有互相冲突。这是内容自检，不是强制用户审批，也不证明真实观众已经理解。
