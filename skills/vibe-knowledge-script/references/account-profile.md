# 项目偏好配置

这四个技能可用于不同创作者的知识视频项目。开始新项目时，从当前对话或项目文件读取以下偏好；没有明确记录的项目设置不应从示例推断。

- 画幅、分辨率和帧率：默认横屏 16:9、1920×1080、30fps；已有工程或用户指定值优先。
- 品牌与水印：只使用当前项目明确提供的名称、位置和呈现规则；未提供时不添加品牌。
- 旁白、音乐与音效：以本次要求和可核实的使用许可为准；旧项目的音乐授权不能转用到新项目。
- 视觉风格：`STYLE_BIBLE.md` 是可复用的暗色系列示例，用户可为自己的系列替换；旧示范关键帧不构成新题材的固定模板。
- 制作方法：按动作需要选择 Canvas、SVG、分层素材、角色动画或 WebGL；Remotion 统一时间和导出。
- 交付范围：遵循本次任务，已有确认的立意、顺序和关键原句保持有效；只请求策划时不启动成片制作。

创作阶段可按 [独立评审](adversarial-review.md) 检查演绎效果和观赏性。子智能体不可用时，应如实说明评审范围。
