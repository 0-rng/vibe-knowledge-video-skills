# Vibe V2：知识发现到视觉事件的共同契约

四阶段使用`visual-events-v2.1`。沿用联网研究、双轨、事实边界、真实字体、暗色基调和默认横屏1920×1080/30fps；用户选择与制作授权继续有效。2026-10-21取消旧图基准和固定三帧审批，按现行STYLE_BIBLE开放视觉表达；每阶段默认执行[独立反驳与优化](adversarial-review.md)。

## 基本单位：一项发现与一段可观看的变化

设计前先问：暂时拿掉解释性文字，观众需要看到什么事件，才能跟随这项知识？从对象与起始状态、意图或受到的作用、动作、阻碍/反馈/条件变化、可观察结果，推到结果支持的认识。不是每段都需人物、冲突或全部环节；并列对照、机制实验、资源流动、时间与空间变化都可以成为事件。

书打开配正文、人物站立配光影、光点移动配金句、三维文字入场、静态图推拉和粒子聚标题可以做氛围、标题或过渡，不能计作核心知识演绎。装饰不因精美而升级成机制。光点、人物距离、门、镜子、书、钟表、连线、球体都只是工具，每次从当前知识的对象、条件、关系与结果重新构思。

## 进入分镜前的知识→视觉转换

| 内容特征 | 优先尝试 | 必须检查 |
|---|---|---|
| 人物关系与情绪 | 具体行为、互动、反应、选择与后果 | 行为可辨，不凭单个动作诊断心理 |
| 因果机制 | 起因→作用→过程→结果 | 作用如何发生；资料支持什么因果 |
| 两种结果 | 同等基准、不同条件的并列对照 | 尺度、时间与其他条件可比 |
| 抽象系统 | 可操作模型、实体关系与状态改变 | 模型假设、操作规则、类比边界 |
| 数据趋势 | 有来源的数据及其变化过程 | 单位、分母、尺度、时间与来源 |
| 认知偏差 | 先形成可见预期，再揭示遗漏条件 | 不把个别观看体验当普遍实验结果 |
| 历史事件 | 时间、人物、空间和关键事件推进 | 史实、重建与不确定部分分开 |
| 哲学命题 | 具体困境、选择、结果与观点关联 | 情境帮助思考，不冒充命题证明 |

先使关系、过程、后果可见，再用必要文字补足。定义、引文、数据、条件可以直接显示；不能为了去字扭曲知识，也不能把全部理论强改成人物小剧场、抽象粒子或三维模型。

## 双轨剧本与稳定关联

- **知识轨**：完整依据、核心逻辑、必要解释、引用和事实边界，供创作及核对。完整正文保留在此，不自动成为字幕。
- **观看轨**：观众实际看到的事件链、动作、状态变化、有限文字与理解推进。下游优先使用此轨。
- 用`claim_id / beat_id / event_id`关联主张、理解节点与可观察事件。一个事件可跨镜，一个镜头可承载多个相关事件；不一镜一句话。
- 候选事件通常3–6个关键节点，按内容增减，不机械凑数。每节点写`起态 → 动作/作用 → 反馈/新结果 → 下一步为何发生 → 新理解`。事件语义可在内容阶段提出，具体资产、取景、坐标和帧号分别交下游；它不是提前锁定导演方案。
- 每事件注明证据性质：真实事件、研究结论、典型情境、虚构演绎、假设模型或视觉隐喻。研究结论的展示模型不等于真实实验记录；虚构故事不能证明未证实因果。
- 必要文字记录`实际显示内容 / 用途 / 为什么不能由画面独立承担 / 对应主张`。专业条件不能仅藏在知识轨，让成片产生绝对化误读。

## 关键状态、无字幕测试与证据等级

第二阶段每套方案明确`起始状态 → 关键变化 → 结果状态`，核心过程用状态说明、关键姿势或按需图示表达，不强制三格或固定图片张数。单帧只支持美术与构图判断，不证明动作能成立。第三阶段导演触发、动作、反馈、结果和观看顺序；第四阶段用真实连续样段检查。

无字幕测试暂时隐藏**解释性字幕**，保留场景必要信息、真实物件文字、轴名、单位和不可缺条件。检查能否识别发生了什么、什么影响什么、怎样变化、结果为何接在前面。不要求无字理解所有专业概念。若基础过程完全读不懂，先改事件与镜头顺序，不能直接堆长字幕。

第三阶段做设计推演、静态状态序列审查及连续验证计划，标明未实测；第四阶段执行真实动画连续检查。不再设置氛围/信息/概念固定三帧美术门槛。状态检查、必要选案图与连续验证服务不同判断，不能互相冒充；每阶段独立评审只在现有证据范围内给结论。

## V2成片新增验收

1. **演绎时长**：大部分有效观看时间展示有意义的事件、机制、关系或状态变化。初始参考约70%，按知识复杂度与阅读需求调整，不作为硬门槛或平台规则。逐区间标`事件演绎 / 必要阅读 / 标题氛围过渡`，重叠区间取并集不重复累计；有效时长为实际内容区间，技术黑场/空尾可排除，必要阅读与标题仍入分母，不能把所有静态段排除以抬高比例。没有实际时轴只写计划值。装饰漂浮、字幕入场、无目的微缩放不计入演绎。
2. **文字依赖**：去掉大多数解释长句，仍可跟随基础事件。必要标签、数据、定义、限定保留；这不是盲目少字竞赛。
3. **变化质量**：每个关键段落有可辨的起态、过程和新状态/对照/揭示；不以切镜数量判定。
4. **连续性**：对象身份与空间一致，反馈晚于触发，接触与遮挡可信，过程不跳步，结果有观看时间，转场保留必要信息。
5. **观赏性**：适度预期、等待、反应、节奏变化和结果反馈，不强制反转或所有镜头同速同情绪。
6. **真实性与可信实现**：事件支持对应主张，边界可见；不得伪造数据、史实、心理诊断或因果。滤镜、灯光、音乐不能补救失败的动作。

记录`主张/事件 → 验证区间 → 实际证据 → 结论与未验证部分 → 修正与复查`。核心事件不成立即样段不通过，即使风格与声音优秀；更换已选核心机制先返回对应创作选择，不擅自换成字幕、光球或静态推拉。结构校验、静态图、连续帧检查、实时播放与主观试听分别记录，不冒称真实观众测试。
